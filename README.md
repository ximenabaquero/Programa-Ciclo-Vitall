# Programa Ciclo Vital

## Un enfoque integral para el SOP y la regularidad menstrual

Landing page para presentación de startup enfocada en el tratamiento integral del Síndrome de Ovario Poliquístico (SOP) y regularidad menstrual.

## Características

- 🎨 Diseño responsive con Tailwind CSS
- 💚 Paleta de colores: coral suave (#FF9999), verde sage (#A8C0B0), blanco
- ✍️ Tipografía: Poppins (Google Fonts)
- 📱 Mobile-first approach
- 🎯 Enfoque investor-friendly

## Secciones

1. **Hero** - Título principal, subtítulo y botón de video pitch
2. **Problema** - Desafíos en el tratamiento del SOP
3. **Solución** - Componentes del programa integral
4. **Mercado** - Oportunidad de mercado y segmentos objetivo
5. **Modelo de Negocio** - Fuentes de ingreso y ventajas competitivas
6. **Propuesta Financiera** - Proyecciones a 3 años e inversión
7. **Equipo** - Fundadores y asesores
8. **Contacto** - Formulario y datos de contacto

## Cómo visualizar

Simplemente abre `index.html` en tu navegador web. La página carga Tailwind CSS y Poppins font automáticamente desde CDNs.

Para desarrollo local con servidor HTTP:
```bash
python3 -m http.server 8080
```

Luego navega a `http://localhost:8080`
